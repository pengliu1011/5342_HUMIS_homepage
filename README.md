# HUMIS Project

## Reflection 

The easiest part of the HUMIS project was building on the two pages we coded together in class. Those examples helped me understand the basic structure and logic of the website. I could follow the same approach to build the other pages and adjust their content and layouts. Having a starting point made the process easier.

The harder part would be starting a completely new project on my own. I can follow and modify the structure we learned, but I would probably need more time to decide how to organize the HTML and CSS without an example. I feel that I understand most of the concepts introduced through the HUMIS project, especially how HTML structures the content and CSS controls its appearance. Working with Flexbox and media queries also helped me understand how a layout can change for different screen sizes.

In the future, I can apply these skills to websites with similar structures. I now have a better idea of how to create responsive pages for both desktop and mobile screens. I would also like to practice building a small website from scratch so I can become more confident in making my own coding decisions.
